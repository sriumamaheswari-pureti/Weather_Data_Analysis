
# 🌦️ Weather Analysis 

## 📌 Project Overview

This project focuses on analyzing a weather dataset using **Python** in a **Jupyter Notebook** environment. The objective is to explore, clean, and extract meaningful insights using data analysis techniques.

---
## 📂 Dataset Description

The dataset contains weather-related attributes such as:

* Temperature
* Wind Speed
* Visibility
* Pressure
* Relative Humidity
* Weather Condition

---

## 📊 Analysis Tasks Performed

* Identified all unique wind speed values present in the dataset
* Calculated how many times the weather was exactly **Clear**
* Counted occurrences where wind speed was exactly **4 km/h**
* Checked for missing (null) values in the dataset
* Renamed the column **'Weather'** to **'Weather Condition'**
* Computed the mean value of **Visibility**
* Calculated the standard deviation of **Pressure**
* Found the variance of **Relative Humidity**
* Extracted all records where **Snow** was recorded
* Filtered records where **Wind Speed > 24 km/h** and **Visibility = 25 km**
* Calculated mean values of each column grouped by **Weather Condition**
* Determined minimum and maximum values for each column by **Weather Condition**
* Retrieved all records where weather condition is **Fog**
* Filtered records where **Weather is Clear OR Visibility > 40**
* Applied combined conditions:

  * Weather is Clear AND Relative Humidity > 50
  * OR Visibility > 40

## ⚙️ Key Pandas Commands Used

* **head()** → Displays the first N rows (default = 5)

* **shape** → Returns total number of rows and columns

* **index** → Provides index information of the dataframe

* **columns** → Displays column names

* **dtypes** → Shows data type of each column

* **unique()** → Returns all unique values in a column

* **nunique()** → Counts number of unique values

* **count()** → Counts non-null values

* **value_counts()** → Shows frequency of unique values

* **info()** → Provides summary of dataframe including
